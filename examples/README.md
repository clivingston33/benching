# Example artifacts

Sanitized, producer-generated snapshots of the canonical v1 contract. Used
by cross-contract tests here and (as synchronized copies) by the dashboard.

## Contents

```text
summary-fireworks-a.json   fireworks / deepseek-v4, decode p50 10 tok/s
summary-fireworks-b.json   fireworks / glm-5.2, decode p50 90 tok/s
comparison-fireworks-ab.json  comparison embedding both summaries
run-a.json / run-b.json    sanitized run metadata for the two runs
```

The two summaries share one provider on purpose: they are the same-provider
regression corpus (distinct `run_id` values must never collapse).

## Provenance

Generated by the real `benching.analytics.analyze` pipeline from synthetic evidence
(two Harbor results and two telemetry rows per run, real pinned WordLevel
tokenizers). `run-*.json` had machine-local `tokenizer.local_cache` paths
sanitized to null afterwards; the summaries keep the local token counts
computed at generation time. No provider keys, prompts, or host paths.

## Regenerating

`tests/test_contract.py::test_examples_match_producer` regenerates these
snapshots from the embedded synthetic evidence and compares them (summaries
byte-identical; the comparison modulo `created_at_utc`/`comparison_id`).
If intentional producer output changes break that test, update the snapshots
by re-running the documented generation and reviewing the diff field by
field — never hand-edit values to make the test pass.
